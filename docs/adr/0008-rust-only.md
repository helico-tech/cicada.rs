# 0008. Cicada for Rust stands alone

Date: 2026-11-09

## Status

Accepted. Supersedes 0001 and 0004

## Context

This repository started as a port of the Kotlin library and promised to keep its contract (ADR 0001, ADR 0004). That
promise means every change to the schema, the HTTP API or a guarantee has to land in two codebases, and it left parts of
this repository depending on the other one: a schema test that reads the Kotlin source, wire types generated by a
Kotlin test, and docs that point there for the rules.

## Decision

Cicada for Rust has no contract with the Kotlin implementation. Mixed fleets (Kotlin and Rust nodes on one store) and
reading databases written by Kotlin nodes are not supported.

This repository owns its guarantees (`docs/architecture.md`), store schema, HTTP API, JSON forms and console.

This ADR does not change the store schema or the wire format. There are no production databases yet (2026-11-09), so
they can still change freely. Once there are, a schema change is a newly appended migration, and any change to the wire
format needs an ADR.

What existed only for Kotlin is removed: `jdbc:postgresql:` URLs, the schema check against the Kotlin source and the
state samples written by Kotlin nodes. The console's wire types (`web/src/api/wire.ts`) were generated from Kotlin
classes; they are now maintained by hand here, and the fixtures test still checks them against the real API.

ADRs 0001–0007 and finished work items keep their Kotlin mentions, as the record of how the code got here.

## Consequences

- The schemas of the two implementations can drift apart. A Kotlin node must not be pointed at a store a Rust node uses.
- `PostgresConnection::parse` refuses `jdbc:postgresql:` URLs; callers use `postgres://` instead. This is a breaking
  change for anyone who passes a JDBC URL.
- Contract hashes no longer need explaining across implementations; the only rule left is that of one node version to
  the next.
- A change to the HTTP wire model needs a hand edit of `wire.ts`. The fixtures test fails when the two disagree on a
  recorded response.
